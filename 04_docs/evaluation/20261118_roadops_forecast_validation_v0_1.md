# RoadOps 예측 품질·불확실성 게이트 v0.1

작성일: 2026-11-18

## 결론

RoadOps의 0·1·3·6시간 점수는 **사고 발생 확률이 아닌 현장 점검 우선순위 시나리오**다. v0.1에서는 과거에 저장된 예측을 나중 시점의 현재 점수와 연결하고, 예측 생성 시점의 값을 그대로 유지하는 기준선과 비교했다.

- 미래 정보 누수: 0건
- 1시간 예측: 2건, 1개 목표 시점만 연결됨
- RoadOps 1시간 MAE: 6.853점
- 현재값 유지 기준선 MAE: 5.000점
- 기준선 대비 개선량: -1.853점
- 3·6시간 예측: 아직 도달한 후행 스냅샷이 없어 검증 대기

따라서 현재 결과는 **`pass_with_limitations`**다. 구조적 누수는 없지만 표본이 너무 적고, 1시간 예측이 기준선보다 좋다는 근거도 없다. 이 결과로 예측 성능 우위를 주장하지 않는다.

## 검증 단위

| 항목 | 기준 |
| --- | --- |
| 예측 단위 | `target_at × link_id × horizon_hours` |
| 예측 버전 | 동일 목표시각의 여러 예측 중 가장 먼저 생성된 값 |
| 실제값 | 목표시각 이후 90분 이내 첫 0시간 현재 점수 |
| 기준선 | 예측을 생성한 스냅샷의 같은 링크 0시간 점수 유지 |
| 주지표 | MAE, 기준선 대비 MAE 개선량, 상·하한 범위 포함률 |
| 최소 근거 | 20건 이상이고 서로 다른 목표시각 3개 이상 |

0시간은 미래 예측이 아니므로 정확도를 계산하지 않고 시점별 산출 가용성만 표시한다.

## 미래 정보 누수 방지

1. 예측 생성시각은 목표시각보다 느지 않아야 한다.
2. 기상 예보의 발표시각과 수집시각은 예측 생성시각보다 느지 않아야 한다.
3. 0시간 관측값은 예측 생성 이후의 시각을 사용할 수 없다.
4. 예측 시점을 10분마다 다시 만들어도 같은 목표시각은 첫 예측만 평가해 중복 표본 부풀리기를 막는다.

위 검사를 통과하지 못하면 검증 상태를 `fail`로 전환한다.

## 자동 축적

운영 갱신 파이프라인은 위험점수 예측 생성 직후 링크 단위 스냅샷을 보존한다. 이후 도달한 0시간 스냅샷을 찾아 새 표본을 자동으로 추가한다. 웹 상단에는 선택한 시점에 따라 다음 상태만 간단히 보여준다.

- `현재값 산출`
- `초기 검증 N건`
- `검증 표본 대기`
- 최소 표본 충족 후 `기준선 대비 개선` 또는 `개선 미확인`
