# RoadOps 자원 배분 정량 평가 v0.1 / Allocation Evaluation v0.1

작성일 / Date: 2026-11-13

## 1. 목적 / Objective

위험순·최근접 기준선과 안전 우선·업무 균형 최적화안을 동일한 제주 도로망 이동시간으로 비교한다. 직선거리 기준선 수치는 운영 가능성 판정에 사용하지 않는다.

## 2. 평가 조건 / Evaluation setup

- 시나리오: 순찰팀 3개, 차량 3대, 근무시간 2시간
- 현장 작업: 9개, 후보 위험점수 합계 294.427
- 이동시간: 제주 방향성 도로망의 제한속도 기반 자유흐름 추정치
- 최적화: 15,755개 실행 가능 조합을 비교하는 결정적 완전탐색
- 반복 성능: 같은 입력으로 최적화 함수 10회 실행

## 3. 비교 결과 / Comparison

| 방법 | 배정 | 위험가중 커버리지 | 도로망 이동시간 | 최대 팀 총소요 | 미배정 | 제약 위반 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 위험순 | 9 | 100% | 166.941분 | 132.302분 | 0 | 1 |
| 최근접 | 9 | 100% | 164.253분 | 130.171분 | 0 | 1 |
| 안전 우선 | 9 | 100% | 90.167분 | 91.197분 | 0 | 0 |
| 업무 균형 | 9 | 100% | 99.999분 | 91.197분 | 0 | 0 |

최근접 기준선과 비교하면 다음과 같다.

- 안전 우선: 이동시간 74.086분·45.1% 감소, 최대 팀 총소요 38.974분·29.9% 감소
- 업무 균형: 이동시간 64.254분·39.1% 감소, 최대 팀 총소요 38.974분·29.9% 감소
- 두 최적화안 모두 근무시간 위반을 1건에서 0건으로 줄이고 위험가중 커버리지 100%를 유지

## 4. 반복 실행 / Repeated runtime

| 반복 | 최소 | 평균 | 중앙값 | p95 최근접 순위 | 최대 | 고유 결과 지문 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 10회 | 2.626초 | 3.032초 | 3.000초 | 3.409초 | 3.409초 | 1개 |

10회 모두 성공했고 같은 두 배분안이 생성됐다. 시간은 현재 개발환경에서 Python 최적화 함수만 측정한 값이며 파일 읽기, 도로망 행렬 생성, 외부 API 호출 시간은 포함하지 않는다.

## 5. 판정과 한계 / Decision and limitations

E1 v0.1은 `pass`다. 네 방법을 동일 지표로 비교했고 최적화 반복 성공과 결정성을 확인했다.

다만 한 개의 9개 현장 시나리오 결과이므로 일반적인 효과 크기로 해석할 수 없다. 이동시간도 실시간 ETA가 아니라 제한속도 기반 자유흐름 추정치다. 통제·폭우 전후 재계획 시간과 변경 범위는 AG2에서 별도 평가한다.
