# 제주데이터허브 점검 근거 기능 / Jeju inspection evidence

2026-11-20. 실제 공개 자료를 연결한 추가 기능이다. 학습형 사고 예측 모델 또는 자동 통제 기능이 아니다.

## 실제 활용

| 자료 | 확보 범위 | 기능 |
| --- | --- | --- |
| [허브 891 노면 상태별 사고](https://jejudatahub.net/data/view/data/891) | 원본 CSV 96행, 2005–2020년 × 6유형. 불완전 15행 | 노면·기간 선택, 건수/사망자/100건당 사망자 집계, 노면별 점검 항목 생성 |
| [허브 863 사고다발지역](https://jejudatahub.net/data/view/data/863) | 공개 CSV 36행, 2017–2022. 전체 API 42행과 다름 | 기존 TAAS 2025년 6행과 연도별 선택. 좌표를 지도에 표시, 연도 간 합산 안 함 |
| [허브 436 붕괴위험급경사지](https://jejudatahub.net/data/view/data/436) | 연결된 공공데이터포털 최신 원본 3행, 2026-06-30 | 위치·등급·정비상태 확인, 같은 행정지역의 점검 참고 |
| [허브 435 자연재해위험개선지구](https://jejudatahub.net/data/view/data/435) | 연결된 공공데이터포털 최신 원본 55행, 2026-06-30 | 해제 이력 필터, 미해제 지구의 지역별 점검 참고 |

급경사지와 재해지구 합계 58행 중 해제 44, 정비 완료 3, 그 외 위치·현장 확인 11행이다. 사업 완료와 지정 해제는 다르다. 광령리는 비고에 2023-05-10 해제가 명시되어 자동 제안에서 제외한다. 실제 좌표·경계가 없어 행정지역 일치만 확인하며 도로의 직접 위험, 통제 또는 추가 점수로 바꾸지 않는다. 서귀포시 자료로 일반화하지 않는다. 행정동/법정동 불일치로 누락될 수 있다.

젖음/습기 2005–2020년: 사고 7,218건, 사망자 226명, 100×226/7,218 = 3.13명/100건. 통행량·노면 노출량이 없으므로 사고 발생확률이나 도로별 위험률로 해석하지 않는다. 입력한 노면은 담당자 선택이며 현재 관측값이 아니다. 빈칸을 0으로 바꾸지 않는다.

노면에 따른 물고임·배수·결빙·제설·해빙 확인 항목과 같은 행정지역의 미해제 지구 확인 항목을 생성한다. 사용자가 `점검계획에 반영`을 누르면 도로별 작업, 추천 순찰코스 및 브라우저 확인 기록에 출처와 기간을 포함한다. 추가 점검 시간이 필요한 경우 담당자가 작업 시간을 조정한다. 서버 영구 저장과 전자결재는 후속 범위이다.

## 출처·조건

- 노면 통계 원천 TAAS, 허브 공개 첨부 CSV 사용. 대응 공공데이터포털 [15095728](https://www.data.go.kr/data/15095728/openapi.do)은 무료·이용허락범위 제한 없음.
- 재해 최신 원본: [15056032](https://www.data.go.kr/data/15056032/fileData.do), 급경사지 [15056033](https://www.data.go.kr/data/15056033/fileData.do). 양쪽 무료·이용허락범위 제한 없음(2026-11-20 확인).
- 허브 863은 공개 미리보기 CSV 범위이다. API 총량 42개 또는 페이지에 적힌 2023년까지를 전부 사용했다고 표기하지 않는다. 전체 API를 추가 수집하려면 프로젝트 인증키와 응답 연도 필드를 별도로 검증한다.
- 기존 허브 1027 및 863의 원본 재배포 조건은 최종 ZIP에 포함하기 전에 개별 확인한다. 사용 여부와 원본 재배포 허락은 구분한다. 현재 기획서는 파생 집계와 실제 UI 캡처, 출처를 제시한다.
- 정규화 JSON에는 원본 SHA-256, 수집일, 기준일, 원천 URL이 들어 있다. 인증키는 포함하지 않는다.

## 재현

정규화 입력 `demo/jeju_inspection_evidence_v0_1.json`은 Git에 포함된다. 원본 CSV를 갱신할 때는 다음 이름으로 준비한 후 실행한다: `surface.csv`, `hotspots_hub.csv`, `steep_slopes.csv`, `natural_hazards.csv`.

```sh
python3 07_scripts/20261120_roadops_prepare_jeju_inspection_evidence.py --input-dir /path/to/official-csv --retrieved-at 2026-11-20
python3 07_scripts/20261113_roadops_build_map_snapshot_v0_1.py --build-status complete
```

그 뒤 대시보드 AGENTS.md에 명시된 Data 플러그인 build를 실행한다. 운영 자동 갱신에도 supplemental JSON을 매번 읽으므로 새 기능의 데이터가 사라지지 않는다. 원시 사고다발·노면·재해 레코드는 점수 입력에 임의 가산하지 않는다. 기존 TAAS 최근 자료 기반 점수와 허브 과거 이력 표시를 구분한다.

## 검증

- Python 관련 검증 18개, JS 점검 근거/확인정책 12개 통과.
- 실제 브라우저: 노면 선택, 집계, 도로별 반영, 추천 순찰코스 항목 표시, 확정 기록에 출처·기간 보존 확인.
- 허브 2022년 6개 중심좌표 표시, TAAS/허브 연도 전환, 재해 14건/해제 포함 58건 전환 확인.
- 브라우저 오류 없음. 지도·확정 버튼이 데이터 패널에 눌려 숨는 문제를 수정하고 클릭으로 재확인.
- 센터 운영 PC에서의 성능·메모리, 실제 도로에서의 점검 효과는 아직 검증하지 않았다.
