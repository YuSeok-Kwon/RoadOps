## 배점과 실제 기여점수

계산 대상은 배점이 0보다 크고 `not_applicable`이 아닌 항목이다. 항목의 배점을 `w`, 근거 반영률을 `c`, 확인된 지수(0~100)를 `v`라 하면 다음과 같다.

- 적용 대상 배점 = 계산 대상의 `Σw`
- 확인된 근거 가중치 = 지수가 확인된 항목의 `Σ(w×c)`
- 근거 반영률 = 확인된 근거 가중치 / 적용 대상 배점
- 항목 기여점수 = `w×c×v / 확인된 근거 가중치`
- 최종 점수 = 항목 기여점수의 합계

‘확인된 근거로 100점 환산’은 근거 반영률이 60% 이상일 때 산정한다. ‘선택한 근거가 모두 있어야 산정’은 계산 대상 근거가 모두 필요하다. 두 방식 모두 도로 관련 근거가 있어야 하고 원천 차단 상태를 무시하지 않는다.

환산 방식에서 설정 배점은 **항목별 최대 기여점수와 같지 않다**. 자료가 확인된 항목끼리 다시 환산되기 때문이다. 최종 점수는 사고 발생확률이 아니라 점검 우선순위 지수다.

### 발표 본문: 사용자 캡처의 평화로

7·10장에는 사용자 캡처의 평화로 **46.1점, 근거 반영률 93%**를 사용했다. 화면 표시 기여점수는 현재 도로 위험상황22.6, 구조6.0, 기상8.6, 교통3.8, 사고다발0.0, 과거 유사상황5.2다. 공항 유입·생활안전은 자료 없음으로 표시되어 막대에서 제외했다.

화면 반올림값의 합계는46.2지만 최종 점수는 원계산값을 반올림한46.1이다. 막대나 합계의 값을 임의로 맞추지 않았다. 완전 근거 방식에서는 미확인 항목이 있으므로 보류된다는 코드 기반 설명을 덧붙였다. 완전 근거 방식의 화면을 별도로 촬영한 것처럼 표현하지 않는다.

용담팀은 2명·120분 조건에서3곳을 제안받았고 이동56.2분, 이동+점검101.2분이었다. 미배정3곳 제외 후 ‘시연 담당자’가 확정한 브라우저 기록은17:51:44 KST다. 화면 값과 원본 해시는 [capture_usage.json](assets/roadops_submission_20261119/capture_usage.json), [capture_manifest.json](assets/roadops_submission_20261119/captures/capture_manifest.json)에 보존했다. 원본 PNG의 수치와 지도 색상은 편집하지 않았다.

## 과거 자료와 지도

과거 유사상황은 같은 도로, 유사도 80% 이상, 근거 반영률 0.6 이상, 24시간 이전~90일 이내, 유효한 사건 기록 등의 조건을 적용한다. 하루 한 번만 세며 3일 상당에서 항목지수 100이 된다. 지도에 표시된 최근 기록이나 다른 도로의 기록이 모두 점수에 들어가지는 않는다.

주변 사고다발지역은 1km 이내 거리감쇠 × 사고건수/40(최대 1)를 사용한다. 과거 사고·도로 구조와 동시에 선택되면 겹치는 지수를 차감한다. 주변 자료가 확인되었으나 추가 근거가 없는 경우는 ‘자료 없음’과 다르다.

범죄주의 지도는 **2025년 과거 범죄 분포에 따른 도로 구간별 주의등급**이다. 출처는 생활안전지도·경찰청 범죄주의구간(전체)이다. 제주시 도심 확대와 원래 노랑→빨강 10단계 범례·연도·출처를 함께 보여준다.

생활안전 점수는 지도 색상이 아닌 **별도의 시 단위 통계**를 사용한다. 이번 자료의 제주시 강력·절도·폭력은 5,128건, 서귀포시는 1,829건이며 제주시 비중은 73.709932%다. 같은 시의 도로에는 동일하게 적용된다. 도로별 범죄위험이나 인구당 발생률로 해석하지 않는다.

## 필수 데이터의 실질적 활용

제주데이터허브 ID 1027 「제주 도로 선형별 교통사고 현황」은 2018~2020년의 연도×선형 계층 집계 **51행**이다. 개별 사고 51건이라는 뜻이 아니다. 원천 복합키 중복·필수 분류 결측·음수 측정값은 0건, 연도·대분류 합계 검증은 9/9였다.

국토교통부 제주 기준망 **37,087개 링크**의 형상 굴곡도로 선형 프록시를 계산해 집계 자료를 결합했다. 원천 데이터가 37,087개 링크의 사고를 직접 관측한 것이 아니다. 초기 굴곡도 임계값 1.02는 제공기관의 공식 분류가 아니라 휴리스틱이다.

현재 구현은 TAAS 링크 위험등급과 이 도로 선형 심각도를 7:3으로 결합해 **‘과거 사고·도로 구조’ 항목의 지수**로 사용한다. 구조 항목의 설정 배점은 담당자가 정한다. 옛 ‘구조위험 상한 25점’ 표현은 사용하지 않는다. 노출 분모가 없으므로 사고가 발생했을 때의 조건부 심각도를 현재 사고 발생확률로 설명하지 않는다.

## 예측과 비교실험의 범위

현재 점수 버전만 필터한 예측 검증 스냅샷은 6개다. 1시간·3시간·6시간 후행 비교 표본은 **0/0/0**, 미래정보 누수 검사 실패는 0이다. 현재 시점의 43개 비교 항목은 상태 산출 가용성 설명용이며 예측 정확도 표본이 아니다. 과거 점수 버전과 합쳐진 16/4/0을 현재 버전의 성능으로 사용하지 않는다.

2026-11-13 고정 배분 비교실험의 총 이동시간은 위험순 166.941분, 최근접 164.253분, 안전 우선 90.167분, 업무 균형 99.999분이었다. **45.1%**는 당시 최근접 대비 안전 우선의 감소율이다. 3팀·3대·2시간·9작업의 저장 입력이고, 제한속도 기반 도로망 추정이다. 현재 사용자 배점의 성능이나 실제 출동 효과가 아니다.

기존 장애 평가는 2026-11-16 12:00 KST의 저장 입력 기준 **6개 시나리오·53개 검사 통과**다. API 실패와 캐시 상태, 잘못된 링크, 배분 불가, 설명 실패 대응을 확인한 범위다. 새 설정 기능 전체의 통합 검증이나 운영 SLA를 뜻하지 않는다.

## 부분 재계획과 승인 기록

이번 통제 What-if는 동부팀(교래 장비고)에만 영향을 준다. 북부팀과 서부팀은 유지되고 완료 업무 1개, 고정 업무 1개를 보존했다. 중앙로 이동 경로가 바뀌었지만 **방문 순서는 바뀌지 않았다**. 전후 제약 위반은 0건이며 담당자 승인이 필요하다. 별도 폭우 예시는 북부팀이 영향을 받으며 방문 순서가 바뀐다.

상세 승인 경로의 `workflowFingerprint`와 `createApprovalRecord`에는 `scoringPolicy`가 포함된다. `WorkflowPanel`은 브라우저 저장소에 감사 로그·승인 기록을 보존한다. 간소 거점 확정 경로는 별도이므로 모든 확정 동작이 동일한 감사 기록이나 안전 확인을 강제한다고 표현하지 않는다. 서버 영속 저장·전자결재·실제 기관 승인 규정 통합은 후속 범위다.
