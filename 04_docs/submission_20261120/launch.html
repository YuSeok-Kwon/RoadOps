통제에 따른 경로·시간 변화

2026년 11월 19일 17:40 저장 자료를 사용합니다. 용담 팀 2명·가용 시간 120분 조건에서, 광령리 점검을 마친 뒤 1100로가 통제된 상황을 가정합니다. 통제 전후 총 예상시간을 같은 기준으로 비교하고, 가용 시간을 5.6분 초과하는 결과를 확인합니다.

발표 사례 실행
시연 순서 · 약 3분
  1. 용담 제설전진기지를 선택하고, AI 자동선택 → 추천 경로 만들기를 누릅니다.
  2. 통제 구간 번호 4050000302, 완료한 점검 1번째 광령리, 이미 사용한 시간 39.8분을 입력합니다.
  3. 방문 대상·순서를 유지하고 통제 전후 필요 시간 비교를 선택한 뒤 대체 경로 자동 계산을 누릅니다.
  4. 통제 전·후 지도와 100.6 → 125.6분, 5.6분 초과 결과를 확인합니다.
완료 소요시간 39.8분은 두 안에 동일하게 적용한 시연 가정값입니다. 실제 통제·출동 사례가 아닙니다.
