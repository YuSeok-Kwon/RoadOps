# 설치·실행 및 사용자 매뉴얼

기준: 2026-11-20 최종 제출본. 경로는 압축 해제한 `RoadOps` 폴더 기준입니다.

## 실행환경

| 구성 | 필요 환경 |
|---|---|
| 포함된 웹 실행본 | Python 3.11 이상, 최근 Chrome/Edge 계열 브라우저. 별도 Python 패키지·Node·API 키 불필요 |
| Python Tool·데이터 처리·테스트 | Python 3.11~3.14, `requirements-runtime.txt`. 노트북은 루트 `requirements.txt` |
| 웹 소스 개발·빌드 | Node.js 22.12 이상, npm, `package-lock.json`으로 `npm ci` |
| 지도 배경 | OpenStreetMap 타일에 접속할 인터넷 연결. 타일이 없어도 도로망·계산 데이터는 ZIP에 포함 |
| 실시간 재수집 | 기관별 네트워크·API 인증키. 저장 자료 데모와 별도 |
| 센터 기준 | i7-8700 / GTX 1060 / RAM 32GB / VRAM 3GB. GPU·모델 가중치 불필요. 해당 PC에서의 실제 실행은 미검증 |

## 처음 시작하기

ZIP 전체를 짧은 경로(예: 문서의 `RoadOps`)에 압축 해제한 뒤 루트 `START_WEB.cmd` 또는 `START_WEB.command`를 실행합니다. 실행이 막히면 터미널을 해당 폴더에서 열고 Windows는 `py -3 run_web.py`, macOS/Linux는 `python3 run_web.py`를 실행합니다. 화면에 표시된 localhost 주소를 열어도 됩니다.

시작 화면에서 두 저장 자료 중 하나를 선택합니다. 각 실행본은 별도 탭으로 열립니다. 테스트를 처음부터 반복할 때는 새 브라우저 세션이나 시크릿 창을 사용하면 이전의 담당자 조건·임시 계획이 섞이지 않습니다. 앱에서 직접 자원·점검 조건을 바꿀 수 있으며 데이터 원본을 자동으로 변경하지 않습니다.

## 일반 점검 계획

1. 거점을 선택하고 기준시점·자료 상태를 확인합니다. 자료가 오래되었다는 안내는 오류가 아니라 저장 자료 시연의 상태 표시입니다.
2. 노면별 사고 통계, 사고다발지역, 위험지구를 살펴봅니다. 최신 기능 실행본에는 허브 891·863·435·436 자료가 포함되어 있습니다.
3. 거점별 기상을 바탕으로 제안된 노면 조건을 확인하고 필요하면 담당자가 수정합니다. 조건에 맞는 점검 항목을 확인해 점검 계획에 반영합니다.
4. 우선순위 항목의 배점을 확인합니다. 기본 배점은 현재 위험 30, 구조 20, 기상·노면 20, 교통 10, 공항 유입 5, 사고다발 8, 과거 유사상황 5, 생활안전 2입니다. 자료가 없는 항목은 확인된 0점과 구분됩니다.
5. 가용 인원·시간, 담당팀 고정·방문 제외 등의 조건을 설정합니다. `AI 자동선택`은 포함된 규칙·계산 도구에 따른 자동 선택 기능입니다.
6. `추천 경로 만들기`를 실행해 방문 순서·이동시간·점검시간을 확인합니다. 필수 방문 대상이 포함됐는지, 해당 경로로 실제 이동할 수 있는지 담당자가 검토합니다.

## 통제 발생 후 비교

발표 사례에서 용담을 선택한 뒤 `AI 자동선택` → `추천 경로 만들기`를 실행합니다. 용담 팀 2명·120분 조건을 확인합니다. 통제 구간 `4050000302`, 광령리 1곳 완료, 이미 사용한 시간 `39.8`을 입력합니다. 방문 대상·순서 유지 비교 옵션을 선택하고 `대체 경로 자동 계산`을 누릅니다.

이 사례는 **1100로의 한 방향 도로 구간 약 398m가 통제된 상황을 가정**한 것입니다. 광령리 점검을 마칠 때까지 사용한 시간은 두 안에 동일하게 적용합니다. 통제 전·후 지도는 같은 범위에서 비교하며, 소길리→예래동 경로가 바뀝니다. 세 곳을 모두 점검하는 데 총 125.6분이 필요해 가용 시간 120분을 5.6분 초과합니다. 확정 버튼은 `출동 조건 검토 필요` 상태로 비활성화됩니다. 담당자는 시간 연장·지원 투입 또는 점검 범위 조정을 검토할 수 있습니다.

## Python Agent

```sh
python 07_scripts/20261113_roadops_run_agent_flow_v0_1.py --strict
```

요청은 `config/agent/roadops_agent_contract_v0_1.json`에 정의된 형식만 지원합니다. 예시:

```sh
python 07_scripts/20261113_roadops_run_agent_flow_v0_1.py --strict --request "팀 3개와 차량 3대로 2시간 안에 현재 위험 기준 순찰계획을 만들어줘. 안전 우선과 업무 균형을 비교해줘."
```

요청한 팀·차량 수가 자원 파일과 다르거나, 입력 자료가 품질 검사를 통과하지 못하거나, 필요한 이동 경로가 없으면 계획을 계산하지 않습니다. 실행 로그·계획 대안·결과 설명은 `02_outputs/data/agent_flow_v0_1`에 저장됩니다. 초기 CLI의 팀 3개 사례와 웹 발표의 용담 1개 팀 사례는 서로 다른 시나리오입니다.

## API 수집과 환경변수

`config/.env.example`을 `config/.env`로 복사하고 필요한 기관 키만 입력합니다. 예시 파일에는 키 값이 없습니다. `config/data_sources.json`에 출처 URL, 인증 변수, 연결 키가 있습니다. 실제 키는 제출물·Git·로그에 넣지 않습니다.

| 변수 | 용도 |
|---|---|
| `JEJU_CITS_API_KEY`, `JEJU_ITS_API_KEY` | 제주 돌발·통제·작업·노면·교통 |
| `DATA_GO_KR_SERVICE_KEY`, `KMA_API_HUB_AUTH_KEY` | 기상 및 공공데이터 수집 |
| `TAAS_API_KEY` | 사고다발지역 등 TAAS 연동 |
| `SGIS_CONSUMER_KEY`, `SGIS_CONSUMER_SECRET` | 행정구역 경계 관련 데이터 |
| `SAFEMAP_API_KEY` | 생활안전·대응시설 등 |

수집 스크립트는 `07_scripts`의 `collect_*`, `audit_*`, `refresh_pipeline` 계열이며 각 `--help`에서 입력 파일·범위를 확인합니다. 원본부터 다시 수집하려면 기관별 이용조건을 확인하고 인증키와 필요한 입력 파일을 준비해야 합니다. 포함된 저장 자료로 실행하거나 경로를 검증할 때는 이 과정이 필요 없습니다. 암호화되지 않은 HTTP API 요청은 기본적으로 차단합니다.

## 오류와 대응

| 증상 | 확인할 내용 |
|---|---|
| Python을 찾을 수 없음 | Python 3.11 이상 설치·PATH 확인. Windows `py -3 --version` |
| `Address already in use` | `run_web.py --port 8766`으로 다른 포트 사용 |
| HTML 더블클릭 후 빈 화면 | 루트의 실행 스크립트 사용. `index.html`과 함께 제공된 `snapshot.*.json` 파일이 같은 폴더에 있어야 함 |
| 지도 배경이 비어 있음 | 인터넷·타일 서비스 연결 확인. 저장된 도로 선과 시간 계산은 별도 |
| `ZoneInfoNotFoundError` | Windows의 CLI 실행 시 `python -m pip install tzdata` |
| 발표 숫자가 다름 | 시작 화면의 발표 사례인지, 용담·2명·120분·39.8분·통제 링크·방문 순서 유지 옵션을 확인 |
| API 인증·응답 실패 | 환경변수·기관 승인·조회 시각·응답 스키마 확인. 저장 자료 데모는 별도 실행 |
| 경로 없음·시간 초과 | 완료 기록·담당팀·필수/제외 조건·통제 링크 확인. 불가능한 계획은 자동 확정하지 않음 |
| `verify_package.py` 해시 차이 | 압축파일을 새 폴더에 다시 해제. 직접 수정·빌드한 사본은 원본 해시와 달라짐 |

## 저장·삭제와 운영 제한

브라우저의 임시 조건·완료 상태·검토 기록은 이 실행본의 브라우저 저장소에 남을 수 있습니다. 기관 서버 저장·다중 사용자 권한·전자결재와 연동하지 않습니다. 최초 상태 확인에는 새 브라우저 세션을 권장합니다. 서버를 종료한 뒤 압축 해제 폴더를 삭제하면 로컬 파일을 제거할 수 있습니다. 브라우저 기록은 브라우저의 사이트 데이터 설정에서 별도로 삭제합니다.

점수는 현장 점검 우선순위를 정하기 위한 참고값이며 사고 확률이 아닙니다. 경로와 소요시간은 도로망의 방향·연결·속도 정보를 바탕으로 추정합니다. 통제 전후 비교에는 신호대기·회전 제한·현장 혼잡·거점 복귀시간이 포함되지 않습니다. 실제 통행 가능 여부를 확인하고 출동 및 변경안을 최종 결정하는 일은 담당자의 역할입니다.
