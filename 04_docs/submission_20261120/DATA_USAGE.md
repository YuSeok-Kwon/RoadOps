## 수집·전처리·분석 흐름

1. CSV·공공 API별 원본 기준일, 수집 시각, 출처 URL과 필드 스키마를 기록합니다. 허브 미리보기와 전체 API의 수집 범위를 구분합니다.
2. 인코딩·숫자·날짜·열 이름을 정리하고 ID를 문자열로 유지합니다. 빈 값·오래된 자료·좌표 미확인은 각각 표시합니다.
3. 제주 도로망을 추출해 좌표계·방향성·노드 연결을 검사합니다. 도로 링크 ID, 좌표 또는 행정지역을 기준으로 결합하고, 어떤 단위로 연결했는지 기록합니다. 행정지역 단위의 참고자료를 정확한 도로 위치로 표시하지 않습니다.
4. 자료의 용도에 따라 우선순위 점수, 통계 근거, 점검 항목, 지도 참고, 통제 제약으로 나눕니다. 위험지구 지정 자체를 자동 폐쇄·점수 가산 근거로 사용하지 않습니다.
5. UI의 기본 배점은 `config/scoring/operator_priority_v0_2.json`의 **30·20·20·10·5·8·5·2**입니다. 초기 데이터 처리에 사용한 가중치와 담당자가 UI에서 설정한 배점은 구분합니다. 자료가 확인된 항목을 기준으로 점수를 환산하며, 자료가 없는 항목을 확인된 0점으로 처리하지 않습니다.
6. 인력·차량·시간·필수 방문·제외 조건을 넣고 이동과 점검시간을 합산합니다. 통제 후 비교는 같은 도로망·속도 비용·완료 시간·방문 순서를 사용합니다.
7. 점수 항목, 원천 시각, 결합·자료 누락, 경로 계산 조건과 결과를 화면·JSON·검증 자료에 남깁니다.

## 이용조건과 제출 자료 정책

2026-11-20 확인한 공공데이터포털의 [노면 상태별 사고 통계](https://www.data.go.kr/data/15095728/openapi.do), [자연재해위험개선지구](https://www.data.go.kr/data/15056032/fileData.do), [붕괴위험급경사지](https://www.data.go.kr/data/15056033/fileData.do), [표준노드링크](https://www.data.go.kr/data/15025526/fileData.do)는 ‘이용허락범위 제한 없음’으로 안내되어 있습니다. 각 제공기관·기준일·원문 URL을 문서 및 데이터 근거에 표시합니다.

허브 863·1027과 인증형 API에 위 조건을 일괄 적용하지 않습니다. 각 허브 상세 페이지와 서비스 이용조건을 따릅니다. 제출 ZIP에는 실행 재현에 필요한 정규화·파생 자료와 출처를 포함하며, 기관별 원본 자료를 모아 별도 데이터 상품처럼 재배포하지 않습니다. 외부 공개·상용 탑재로 범위를 넓힐 때는 해당 기관의 원본 및 2차 가공 자료 배포 조건을 다시 확인해야 합니다. 원본 수집용 키는 포함하지 않습니다.

제출 사본에는 저장 자료로 시연하며 실시간 수집을 사용하지 않는다는 표시만 메타데이터에 추가했습니다. 점수·경로 계산에 사용하는 입력값과 원래 기준시각은 변경하지 않았습니다. 변경 내역을 확인할 수 있도록 원본 입력과 제출 사본의 해시를 함께 보관합니다.
