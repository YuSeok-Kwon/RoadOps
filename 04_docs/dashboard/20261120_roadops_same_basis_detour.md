## 앱 동작

기존 예산 내 재배분 기능에 ‘방문 대상·순서를 유지하고 통제 전후 필요 시간 비교’를 추가했다. 이 모드는 모든 방문을 유지할 때 필요한 시간을 계산한다. 예산을 초과해도 예상치를 보여주지만 `previewOnly` 및 `review_required`로 반환하며 계획 확정 버튼을 비활성화한다. 초과를 자동 승인하지 않고 담당자가 시간 연장·지원 여부를 판단하도록 한다.

통제 전/후 지도 전환에서 두 경로의 합집합으로 범위를 잡아 배율과 위치가 유지된다. 완료 구간과 광령리→소길리 선은 같고, 소길리→예래동 선이 달라진다. 실제 UI 캡처에 도형이나 가짜 경로를 합성하지 않았다.
