# RoadOps Agent 도구 흐름 v0.1 / Agent Tool Flow v0.1

작성일 / Date: 2026-11-13

## 1. 목표 / Objective

공무원의 자연어 요청 한 문장을 자원·위험·도로망·최적화 도구로 연결하고, 수동 중간 조작 없이 실행 가능한 순찰 대안과 감사 로그를 생성한다.

대표 요청:

> 팀 3개와 차량 3대로 2시간 안에 현재 위험 기준 순찰계획을 만들어줘. 안전 우선과 업무 균형을 비교해줘.

## 2. 도구 흐름 / Tool flow

| 순서 | Tool | 역할 | 실제 실행 상태 |
| ---: | --- | --- | --- |
| 1 | `request_interpreter` | 팀·차량·시간·위험시점·요청 대안 해석 | `pass` |
| 2 | `data_quality_gate` | 자원 검증, 요청과 자원 일치, 입력 품질보고서 확인 | `pass_with_limitations` |
| 3 | `risk_task_builder` | 현재 위험 이벤트를 링크 단위 현장 작업으로 통합 | `pass` |
| 4 | `travel_time_gate` | 108개 도로망 경로와 작업 호환성 확인 | `pass` |
| 5 | `allocation_optimizer` | 안전 우선·업무 균형 대안 생성 | `pass` |
| 6 | `plan_validator` | 중복·근무시간·경로·하드 제약 독립 재검사 | `pass` |
| 7 | `result_explainer` | 지표·한계·승인 필요 여부를 사용자 응답으로 변환 | `pass` |

각 Tool은 `입력 요약`, `출력 요약`, `상태`, `제한사항`을 남긴다. 전체 7행 감사 로그는 `tool_trace.jsonl`로 별도 저장한다.

## 3. 실제 실행 결과 / Result

- 현재 시간지평 위험예보 22행 중 순위 가능한 이벤트 14건 확인
- 동일 링크 중복을 합쳐 현장 작업 10개 생성
- 운영자 제외 1개를 빼고 9개 작업을 배분 대상으로 사용
- 제주 방향성 도로망 경로 108개와 작업 ID 호환성 통과
- 15,755개 실행 가능 조합 비교
- 두 대안 모두 9개 배정, 미배정 0개, 위험가중 커버리지 100%, 제약 위반 0건

| 대안 | 도로망 이동시간 | 최대 팀 총소요 | 미배정 | 제약 위반 |
| --- | ---: | ---: | ---: | ---: |
| 안전 우선 | 90.167분 | 91.197분 | 0 | 0 |
| 업무 균형 | 99.999분 | 91.197분 | 0 | 0 |

최종 상태는 `pass_with_limitations`다. Agent 자체 실행 실패가 아니라 입력 데이터 두 종류가 제한사항과 함께 품질 게이트를 통과했기 때문이다.

## 4. 안전장치 / Guardrails

- 요청의 팀·차량 수 또는 시간지평이 자원 시나리오와 다르면 배분 전에 중단한다.
- 품질보고서가 `fail`이거나 실패 검사가 남아 있으면 위험 작업을 만들지 않는다.
- 도로망 행렬에서 필요한 origin–destination 쌍이 빠지면 최적화를 실행하지 않는다.
- 최적화 이후에도 작업 중복, 경로 상태, 근무시간, 하드 제약을 독립적으로 재검사한다.
- 결과에는 `manual_approval_required=true`를 고정해 자동 현장 지시를 막는다.
- 캐시 데모와 실시간 입력을 구분하고 도로시간이 실시간 ETA가 아님을 표시한다.

## 5. 현재 한계 / Limitations

- 자연어 해석은 제출 환경에서 재현 가능한 한국어 제한 문법이며 범용 LLM 해석이 아니다.
- 이번 실행은 2026-11-12 22:00 KST 저장 스냅샷을 사용하므로 현재 실시간 상태가 아니다.
- 도로망 시간은 제한속도 기반 자유흐름 추정치이며 ITS 혼잡과 회전제한을 반영하지 않는다.
- 현재 Agent는 최초 계획만 생성한다. 통제·폭우 발생 후 완료·고정 업무를 보존하는 부분 재계획은 AG2 범위다.

LLM은 후속 단계에서 표현이 다양한 요청을 구조화하고 설명 문장을 조정하는 층으로 추가할 수 있다. 위험점수·경로·최적화·제약 판정은 계속 검증된 Python Tool 결과만 사용한다.
