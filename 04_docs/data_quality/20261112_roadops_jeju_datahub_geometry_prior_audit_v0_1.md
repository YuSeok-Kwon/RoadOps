# 제주데이터허브 도로 선형 심각도 선행값 감사 v0.1 / Jeju Data Hub Geometry Severity Prior Audit v0.1

작성일 / Date: 2026-11-12

## 결론 / Decision

제주데이터허브 인증 데이터 `제주 도로 선형별 교통사고 현황`의 실제 CSV 51행을 확보해 RoadOps 파이프라인에 연결했다. 원본은 2018~2020년 제주 교통사고를 도로 선형 계층별로 집계하며, 연도·대분류·중분류·소분류 복합키 중복과 결측, 음수 측정값은 0건이었다. 9개 연도·대분류 그룹 모두 최상위 합계가 세부행 합계와 일치했다.

다만 이 데이터에는 도로 길이, 통행량, 차량주행거리 같은 노출 분모가 없다. 따라서 사고 건수를 링크별 사고 발생확률로 사용하지 않는다. RoadOps는 `커브,곡각`과 `직선`에서 사고가 발생했을 때의 사망·부상 강도만 조건부 구조 심각도 선행값으로 사용한다.

국토교통부 제주 기준망 37,087개 링크의 WKT 형상에서 선형 굴곡 프록시를 계산해 전 링크에 1:1로 연결했다. 현재 통합 현장 이벤트의 점수화 대상 26건, 14개 링크에는 모두 선행값이 결합됐다. 이 선행값은 아직 최종 위험점수에 가산하지 않으며, TAAS 링크 위험과의 중복 계산 방지 규칙을 위험점수 v0.1에서 먼저 확정한다.

## 데이터 단위 / Grain

- 원천 단위: 연도 × 도로선형 대분류 × 중분류 × 소분류 집계 1행
- 원천 행: 51행
- 연도: 2018~2020년, 매년 17행
- 계층: 최상위 합계 9행, 중간 합계 12행, 세부행 30행
- 측정값: 사고 건수, 사망자 수, 부상자 수
- 선행값 계산: 대분류의 최상위 합계 3개 연도를 합산

최상위 합계, 중간 합계, 세부행을 함께 더하면 같은 사고가 중복 계산된다. 선행값은 `중분류=합계`, `소분류=합계`인 최상위 행만 사용하고, 세부행은 합계 검증에만 사용한다.

## 조건부 선형 심각도 / Conditional geometry severity

| 선형 | 사고 | 사망 | 부상 | 사고 100건당 사망 | 사고당 부상 | 직선 대비 사망지수 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 커브·곡각 | 1,068 | 30 | 1,788 | 2.809 | 1.674 | 1.747 |
| 직선 | 11,441 | 184 | 17,541 | 1.608 | 1.533 | 1.000 |

커브·곡각의 사고 100건당 사망자 수는 직선의 1.747배였다. 이는 **사고가 발생한 경우의 조건부 심각도 차이**이며, 커브 도로에서 사고가 1.747배 자주 발생한다는 뜻이 아니다. 통행 노출 분모가 없으므로 발생빈도 비교는 지원하지 않는다.

`기타구역` 172건은 도로 링크 선형으로 대응할 수 없어 링크 선행값에서 제외했다.

## 링크 프록시 결합 / Link proxy mapping

각 기준망 링크의 WKT 폴리라인 길이를 양 끝점 직선거리로 나눈 굴곡도(`sinuosity`)를 계산했다.

- `sinuosity >= 1.02`: `curve`
- `sinuosity < 1.02`: `straight`
- 형상 파싱 실패: 결합 보류

| 결과 | 링크 | 비율 |
| --- | ---: | ---: |
| 커브 프록시 | 5,928 | 16.0% |
| 직선 프록시 | 31,159 | 84.0% |
| 형상 오류·미결합 | 0 | 0.0% |
| 합계 | 37,087 | 100.0% |

1.02는 제공기관 기준이 아니라 작은 좌표 굴곡을 직선으로 남기기 위한 RoadOps 초기 휴리스틱이다. 위험점수에 사용하기 전에 표본 도로의 수동 확인과 민감도 분석이 필요하다.

현재 통합 이벤트에서 점수화 가능한 26건은 모두 결합됐다. 24건은 직선, 2건은 커브 프록시이며, 고유 링크 기준으로는 직선 12개와 커브 2개다.

## 사용 규칙 / Use policy

허용:

- `fatalities_per_100_accidents`를 사고 발생 시 조건부 사망 심각도 맥락으로 사용
- `injuries_per_accident`를 조건부 부상 규모 맥락으로 사용
- 원천 기간과 선형 프록시를 근거와 함께 사용자에게 표시

금지:

- 사고 건수를 링크별 사고 발생위험으로 해석
- 커브 프록시를 제공기관의 공식 도로선형 분류로 표현
- TAAS 링크 위험과 독립적인 점수로 단순 가산
- 2018~2020년 집계를 현재 실시간 사고상황으로 표현

## 자동화 품질 게이트 / Automated gates

- 원본 파일 SHA-256 고정
- 예상 열 이름과 순서 검사
- 복합키 고유성, 필수 분류, 비음수 측정값
- 최상위 합계와 세부행의 연도·대분류별 재조정
- 문서 수집기간의 연도 완전성
- 기준망 링크 ID 고유성과 형상 파싱
- 링크별 선행값 최대 1행
- 통합 이벤트에서 배제된 행의 링크 선행값 차단

## 한계와 후속 확인 / Limitations and follow-up

1. 노출 분모가 없어 발생위험을 계산할 수 없다.
2. 원천 기간이 2018~2020년으로 오래돼 최신 도로환경 변화를 반영하지 못한다.
3. 원 데이터가 TAAS이므로 현재 TAAS 링크 위험과 정보가 겹칠 수 있다.
4. 링크 선형 분류는 WKT 굴곡도 기반 휴리스틱이다.
5. 데이터 상세 페이지에서 별도 라이선스를 확인하지 못했으므로 제출 ZIP에 원본을 포함하기 전에 이용조건을 확인해야 한다.
