# C-ITS 공간 결합 품질 감사 v0.1 / C-ITS Spatial-Join Quality Audit v0.1

작성일 / Date: 2026-11-12

## 결론 / Decision

2026-11-12 13:52 KST에 새로 수집한 C-ITS 35건 중 27건(77.1%)만 도로별 위험점수 입력으로 허용했다. 기준 도로망 37,087개 링크의 전체 폴리라인 형상을 사용했고, 도로망 구축 오류는 0건이었다.

8건은 자동 배제했다. 노면기상 5건은 가장 가까운 링크와 두 번째 링크의 거리 차가 5m 미만이었고, 도로위험 2건은 유효한 소스 `link_id`를 갖지만 해당 도로 형상에서 142.1m·195.2m 떨어져 있었다. 도로작업 1건은 좌표가 `90.00000001, 180.00000001`로 제주 범위를 벗어났다.

자동 배제된 레코드도 삭제하지 않고 감사 로그에 보존한다. 운영자가 근거를 확인하기 전에는 특정 도로의 자원 배분 점수에 반영하지 않는다.

## 데이터 단위 / Grain

- 원천 단위: C-ITS 소스와 수집 스냅샷의 레코드 1건
- 결합 단위: 원천 레코드 1건당 기준 도로 링크 최대 1개
- 기준망: 2026-10-14 국토교통부 전국표준 노드링크 제주 부분집합 37,087개 링크
- 좌표계: C-ITS와 기준망 모두 EPSG:4326
- 시각: `snapshot_collected_at`은 원천 발생시각이 아닌 RoadOps 수집시각

## 결합 규칙 / Matching rules

1. 유효한 10자리 `link_id`가 기준망에 있으면 ID 정확 결합을 우선한다.
2. ID 결합도 좌표와 링크 전체 형상의 최단거리가 30m를 초과하면 `coordinate_conflict`로 배제한다.
3. ID가 없거나 기준망에 없으면 좌표 기반 최근접 링크를 탐색한다.
4. 최근접 거리가 30m 이하이고 2순위와의 거리 차가 5m 이상일 때만 `spatial_fallback`으로 허용한다.
5. 최근접 후보가 2순위와 5m 미만 차이면 `ambiguous`, 좌표가 없거나 제주 범위 밖이면 `invalid`로 배제한다.

30m 기준은 2026-10-27 스냅샷에서 좌표가 있는 정상 ID 정확 결합 26건의 최대 거리가 22.9m였던 것을 기준으로 설정한 초기 보수선이다. 제공기관 SLA가 아니며, 더 많은 기간의 관측과 수동 표본 확인 후 조정해야 한다.

## 품질 판정 / Findings

### 1. 노면기상 링크 모호성

- 실패: 12건 중 5건(41.7%)의 1·2순위 거리 차가 5m 미만이었다.
- 위험: 양방향 링크나 교차로 인접 링크 중 틀린 방향을 선택하면 위험점수가 잘못된 현장 자원에 전파될 수 있다.
- 심각도 / 지지도: High / High. 거리가 전체 도로 형상에서 직접 계산됐고 모든 레코드의 `heading=-1`이어서 방향 보조 근거가 없다.
- 조치: 5건은 `ambiguous`로 보존하고 위험점수에서 제외한다. 장비 ID·설치 도로 메타데이터를 확보하면 방향성 없는 도로 단위 결합으로 보완한다.

### 2. 도로위험 ID-좌표 충돌

- 실패: 22건 중 2건(9.1%)의 유효한 `link_id`와 좌표가 각각 195.2m, 142.1m 떨어졌다.
- 위험: ID만 믿으면 좌표가 가리키는 현장과 다른 도로에 자원이 배정될 수 있다.
- 심각도 / 지지도: High / High. 30m 기준을 4.7·6.5배 초과했고, 동일 좌표의 대체 후보는 7.1m에 있었다.
- 가능 원인: C-ITS와 2026-10-14 기준망의 링크 버전 차이, 방향 링크 부여 차이, 또는 원천 레코드 오류. 현재 자료만으로 원인을 확정하지 않는다.
- 조치: 소스 ID를 임의로 대체하지 않고 `coordinate_conflict`로 보류한다. 제공기관의 현재 노드링크 버전을 확인하고 ID 매핑을 별도 검증한다.

### 3. 도로작업 잘못된 좌표

- 실패: 1건의 좌표가 제주 범위를 벗어나고, 소스 `link_id`도 기준망에 없었다.
- 위험: 좌표 보조 결합과 ID 결합을 모두 사용할 수 없다.
- 심각도 / 지지도: High / High. 영향 범위는 1건이지만 해당 소스의 현재 레코드 전체이다.
- 조치: `invalid`로 보존하고 점수에서 제외한다. 도로명·작업 ID를 활용한 별도 규칙은 수동 확인 후에만 추가한다.

## 시계열 비교 / Temporal comparison

2026-10-27 스냅샷은 47건 중 41건(87.2%), 2026-11-12 스냅샷은 35건 중 27건(77.1%)이 초기 게이트를 통과했다. 두 시점의 전체 레코드 구성이 다르고 관측 횟수가 적으므로 10.1%p 하락을 시세 트렌드로 해석하지 않는다. 중요한 변화는 11월 12일 도로위험에서 ID-좌표 충돌 2건이 새로 관측된 점이다.

각 시점의 결과는 발생 시각 기준 트렌드가 아니라 수집 시각 기준 표본이다.

## 자동화 품질 게이트 / Automated gates

- 기준망 `link_id`·노드 ID 형식과 고유성
- 링크 WKT 형상 파싱; 오류 시 시작·종료점 보조 사용과 이슈 기록
- C-ITS 좌표의 제주 범위 유효성
- ID 정확 결합의 좌표-형상 거리 30m 초과 여부
- 공간 보조 결합의 최근접 거리 30m 이하 여부
- 1·2순위 링크 거리 차 5m 이상 여부
- `exact_link_id`, `spatial_fallback`, `ambiguous`, `unmatched`, `invalid` 분리 집계
- 배제 레코드의 원본·최근접 1·2순위 후보·거리 보존
