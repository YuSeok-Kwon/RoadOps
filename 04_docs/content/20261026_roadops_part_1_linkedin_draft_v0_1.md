# AI와 함께 제주 도로위험 순찰배치 Agent를 만들고 있습니다 — RoadOps 첫 기록

“오늘 순찰차 4대를 어느 도로에 먼저 보내야 할까?”

짧은 질문이지만 제대로 답하려면 먼저 서로 다른 데이터가 정말 같은 도로를 가리키는지 확인해야 합니다. 과거 교통량이 기록된 도로, 실시간 위험상황이 발생한 도로, 통제 중인 도로, 비가 올 것으로 예상되는 지역을 하나의 기준 위에 올리지 못하면 정교한 배치 알고리즘도 잘못된 입력을 빠르게 처리할 뿐이기 때문입니다.

그래서 RoadOps의 첫 작업은 위험점수나 경로 최적화가 아니었습니다. 제주 도로 데이터, C-ITS, 기상청, TAAS를 실제로 결합할 수 있는지부터 검증했습니다. 국토교통부 전국표준 노드링크에서 제주 노드 27,656개와 링크 37,087개를 직접 추출해 기준 도로망도 확보했습니다.

가장 중요한 발견은 공식 명세상 제주 도로 구간과 C-ITS·ITS 데이터가 공통으로 `link_id`를 제공한다는 점이었습니다. 좌표가 가까운 도로를 추정하기 전에 같은 ID가 있는지부터 확인할 수 있습니다.

다만 ID가 없거나 기준 도로망과 일치하지 않는 경우도 고려했습니다. 이때만 초기 기준인 100m 이내의 공간 보조 매칭을 사용하고, 임계값 밖의 이벤트는 가까운 도로에 억지로 붙이지 않습니다. 정확 조인, 공간 보조, 미결합을 각각 기록해 담당자가 근거의 차이를 확인할 수 있도록 했습니다.

[AI를 어떻게 활용했나]

저는 AI를 결론을 대신 만드는 도구보다 기획자·개발자·리뷰어에 가까운 협업 파트너로 사용했습니다.

대화로 문제를 “위험한 도로 계산”보다 앞선 “데이터 결합 가능성 검증”으로 좁히고, 공식 명세와 API 문서에서 필요한 연결 키를 추적했습니다. 이후 데이터 소스 설정, 접근성 점검 코드, 공간 결합 함수와 실패 사례 테스트를 구현하고 결과를 다시 검토했습니다.

반면 링크 ID 검증, 좌표계 변환, 노드 참조, 연결망 탐색과 결합률 집계는 Python 코드가 재현 가능하게 수행합니다. 최종 제품에서도 LLM은 공무원의 요청을 구조화하고 결과를 설명하되, 위험점수와 자원배분은 명시적인 규칙과 최적화 도구가 계산하도록 분리할 계획입니다.

[현재까지 구현한 범위]

• 제주 도로·C-ITS·ITS·기상청·TAAS 데이터 소스 9개 정의

• 실제 제주 노드 27,656개·링크 37,087개 추출

• ID·좌표·참조·형상·속성·연결성 14개 품질 게이트 통과

• `link_id` 우선 결합과 거리 기반 공간 보조 매칭

• 임계값 밖 이벤트를 강제로 배정하지 않는 감사 로그

• 기상청 5km 격자 변환과 TAAS 도로 선분 입력 생성

• 문서 접근성과 API 키 상태를 분리한 읽기 전용 점검

• 정확 조인·공간 보조·미결합 등 22개 자동화 테스트

처음 예상과 다른 문제도 발견했습니다. 제주 C-ITS·ITS 공식 안내의 운영 API 주소는 평문 HTTP로 적혀 있었습니다. 현재 환경에서 HTTPS 연결을 확인하지 못했기 때문에, 운영 단계에서는 제공기관 확인과 백엔드 프록시·제한된 키 같은 보호 대책이 필요합니다.

기준 도로망은 14개 게이트를 모두 통과했지만, 이 수치를 실시간 데이터 결합 정확도로 해석하면 안 됩니다. 현재 C-ITS·ITS API 키가 없어 최신 실응답과의 ID 일치율은 아직 측정하지 못했습니다. 또한 추출 범위는 제주 본섬 중심이므로 부속 도서 커버리지도 추가 검증해야 합니다.

[최종 목표]

RoadOps의 목표는 사고 발생을 단정하거나 긴급 출동을 자동 지시하는 것이 아닙니다.

공무원이 가용 인력·차량·근무시간을 입력하면 Agent가 데이터의 갱신시각과 결합 상태부터 검사하고, 안전 우선·이동시간 우선·업무량 균형 같은 복수의 순찰안을 제시하는 것이 목표입니다. 신규 통제나 기상 변화가 생기면 완료된 업무와 담당자가 고정한 업무는 유지하면서 영향받은 팀만 다시 배치합니다. 모든 계획은 근거와 미배정 고위험 구간을 함께 보여주고 담당자가 최종 승인합니다.

다음 단계에서는 실제 API 응답을 이번에 확보한 기준망과 조인해 ID 유효율과 정확 조인율을 검증하고, 100m라는 초기 공간 보조 임계값도 조정한 뒤 위험점수 설계를 시작할 예정입니다.
