# RoadOps 설명 가능한 위험점수 v0.1 / Explainable Risk Score v0.1

작성일 / Date: 2026-11-12

## 결론 / Decision

RoadOps 위험점수 v0.1은 통합 C-ITS 이벤트 1건당 1행을 유지하면서 현재 이벤트, 구조위험, 기상·노면, 교통 노출의 네 축을 0~100점으로 계산한다. 이 점수는 사고 확률이 아니라 **현장 확인과 순찰 검토의 우선순위**다.

2026-11-12 17:58 KST에 새로 수집한 C-ITS 25건 중 18건에 점수와 구성 근거를 생성했다. 6건은 도로 결합 배제, 1건은 교통량과 TAAS가 모두 없어 근거 커버리지 60% 미만으로 `hold`했다. C-ITS가 제공기관 발생시각을 주지 않아 점수 18건 모두 `degraded`이며 운영자 검토가 필요하다.

## 운영 판단 / Operating decision

- `usable`: 정확 도로 결합, 최신 시각, 필수 근거가 모두 있는 점수
- `degraded`: 공간 보조 결합, 제공자 발생시각 부재, 일부 근거 결측 등으로 운영자 확인이 필요한 임시 점수
- `hold`: 도로 결합 배제, C-ITS 스냅샷 60분 초과, 근거 커버리지 60% 미만으로 점수를 발행하지 않음

`degraded`는 순위 후보로는 보여줄 수 있지만, 자원 배분 확정은 공무원의 승인 후에만 가능하다. `hold`는 순위와 배분 입력에서 제외하되 원본 근거와 보류 사유를 보존한다.

## 점수 구조 / Score structure

| 구성요소 | 최대 가중치 | 입력 | v0.1 원칙 |
| --- | ---: | --- | --- |
| 현재 이벤트 | 35 | C-ITS 위험·통제·작업 | 제공자 코드 사전이 없어 소스 종류별 기본점수만 사용 |
| 구조위험 | 25 | TAAS 등급 + 제주데이터허브 ID 1027 | 하나의 25점 바구니 안에서 70:30으로 결합 |
| 기상·노면 | 25 | 기상청 예보 + C-ITS 노면센서 | 강수·바람·시정·마찰·노면온도 중 가장 큰 위험신호를 사용 |
| 교통 노출 | 15 | ITS 속도·점유율 + 제한속도 | 제한속도 대비 실제속도와 점유율 중 큰 신호를 사용 |

노면기상 센서행은 독립적인 돌발 이벤트가 아니므로 현재 이벤트 35점을 적용하지 않는다. 이 경우 적용 가능한 최대 가중치는 65점이며, 가용 근거 가중치로 다시 0~100으로 환산한다.

## 결측과 불확실성 / Missingness and uncertainty

결측 피처를 0점으로 바꾸지 않는다.

- 추정점수: 현재 가용한 근거 가중치만으로 재정규화
- 하한: 결측 근거가 모두 0점일 경우
- 상한: 결측 근거가 모두 100점일 경우
- 근거 커버리지: 관측된 근거 가중치 / 적용 가능한 전체 가중치

예를 들어 교통 15점 근거가 없으면 교통을 0점으로 간주하지 않고, 추정점수와 함께 교통 요소로 넓어진 상·하한을 제공한다. 커버리지가 60% 미만이면 추정점수 자체를 발행하지 않는다.

## TAAS–제주데이터허브 중복 방지 / Double-counting control

제주데이터허브 ID 1027은 원 제공처가 TAAS다. 따라서 TAAS 링크 위험과 선형 심각도를 독립 점수로 더하지 않는다.

```text
구조위험 = 0.70 × TAAS 등급점수
             + 0.30 × 제주데이터허브 선형 조건부 심각도
구조위험의 전체 기여도 상한 = 25점
```

TAAS가 오류나면 선형 근거만으로 임시 추정하고 구조위험 근거 커버리지를 30%로 표시한다. 직선의 선형점수 0은 사고위험 0을 뜻하지 않고, 직선 대비 추가 사망 심각도가 없다는 뜻이다.

점수 등급은 `high` 1건, `moderate` 14건, `low` 3건이다. 등급은 사고 확률이 아니라 순찰 검토 우선순위로, `low < 25`, `moderate 25~49.999`, `high 50~74.999`, `critical >= 75`의 임시 정책 구간을 사용한다.

1순위는 516로의 노면기상 행으로 53.846점이다. 주요 근거는 C-ITS 시정 원시값 `4`, 제한속도 대비 실제속도, TAAS 등급이다. 다만 시정 단위를 공식 자료에서 확정하지 못해 미터로 해석한 가정 플래그와 `degraded`를 남겼다. 단위 확정 전에는 운영자가 원시값을 반드시 재확인해야 한다.

## 품질 게이트 / Quality gates

- 입력 1행당 출력 1행 보존
- `event_id` 유일성
- 0~100 점수 범위
- 하한 <= 추정점수 <= 상한
- `hold` 행의 점수 null
- `excluded` 행의 `hold` 강제
- 구성요소 기여도 합계와 최종점수 일치
- `--as-of`를 같이 주면 동일 입력에 동일 결과

## 한계 / Limitations

1. 가중치와 구간값은 사고 라벨로 학습한 모델이 아니라 설명 가능한 v0.1 정책값이다.
2. C-ITS 제공기관 발생시각이 없어 수집시각을 대신 사용하며, 현재 점수는 모두 `degraded`다.
3. 도로위험 코드 사전이 확인되기 전에는 `258`·`534`·`1286` 등을 서로 다른 심각도로 해석하지 않는다.
4. C-ITS 시정은 임시로 미터 단위로 해석하며 해당 행에 가정 플래그를 남긴다.
5. ITS 교통량은 집계 구간과 0이 많은 원인을 확정하기 전에는 점수에 쓰지 않는다.
6. 같은 링크의 복수 제공자 레코드는 이벤트별로 유지되므로, 자원 배분 전에 현장 작업 단위로 묶는 규칙이 필요하다.
