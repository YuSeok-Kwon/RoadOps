# RoadOps 도로망 이동시간 행렬 v0.1 / Road-Network Travel-Time Matrix v0.1

작성일 / Date: 2026-11-13

## 결론

T1은 외부 길찾기 API 없이도 제출 환경에서 재현되도록 국토교통부 제주 방향성 노드·링크망으로 자유흐름 최단시간 경로를 계산한다. 팀 3곳과 배분 대상 현장 9곳을 출발점으로 사용해 팀→현장과 현장→현장 108개 경로를 만들었으며, 기본 시나리오에서는 108개 모두 성공했다.

이 결과는 실시간 ETA가 아니다. 링크 형상 길이와 제한속도를 사용한 `free_flow_speed_limit_estimate_not_live_eta`다. 그러나 직선거리보다 실제 도로 연결성과 방향을 반영하므로 A3 제약 최적화의 입력으로 사용할 수 있다.

## 직선거리 기준선 재검

T1 행렬로 A2의 기존 방문 순서를 그대로 다시 계산하자 두 기준선 모두 실제 도로시간 기준으로는 근무시간을 초과했다.

| 기준선 | 기존 직선 추정 이동시간 | 도로망 이동시간 | 최대 팀 총소요 | 2시간 초과 |
| --- | ---: | ---: | ---: | ---: |
| 위험순 | 118.103분 | 166.941분 | 132.302분 | 1개 팀, 12.302분 |
| 최근접 | 107.818분 | 164.253분 | 130.171분 | 1개 팀, 10.171분 |

위험순은 이동시간이 48.838분, 최근접은 56.435분 증가했다. 따라서 직선거리 기준선은 비교 대상으로는 남기되 운영 가능성 판정에는 사용할 수 없다. A3는 처음부터 도로망 이동시간을 사용해야 한다.

## 통제·실패·캐시 안전장치

- C-ITS 활성 통제 링크와 사용자가 지정한 링크를 방향성 그래프에서 제거한다.
- 생성된 모든 `route_link_ids`에 통제 링크가 없는지 품질검사한다.
- 우회로가 없으면 직선거리로 몰래 대체하지 않고 `unavailable`과 `no_directed_network_path`를 반환한다.
- 통제 링크 자체가 점검 대상이면 링크를 통과하지 않고 시작 노드까지 접근한 `ok_approach_only`로 구분한다.
- 입력 데이터·자원·작업·통제·파라미터 해시가 같을 때만 캐시를 재생한다.
- 계산과 캐시 재생은 같은 행 스키마를 사용하고 `source_mode`만 구분한다.

실제 링크 `4060461602`를 통제로 주입한 시험에서는 108개 중 89개가 우회 또는 정상 접근했고, 19개는 방향성 경로가 단절돼 `unavailable`이 됐다. 통제 링크를 통과한 경로는 0건이었다. 합성망 테스트에서는 대체 경로가 있을 때 더 느린 우회로를 선택하는 것도 확인했다.

## 현재 한계

1. 제한속도 기반 자유흐름 추정치라 현재 ITS 정체를 반영하지 않는다.
2. 원본 압축파일의 회전제한 정보는 v0.1 그래프에 아직 반영하지 않았다.
3. 팀 출발점은 가장 가까운 노드까지 직선 연결하며 이 연결구간을 별도 필드로 표시한다.
4. 통제 링크 접근은 시작 노드 기준이라 현장 접근 지점의 안전성은 담당자 확인이 필요하다.
