# RoadOps 자원 입력과 기준선 배분 v0.1 / Resource Inputs and Allocation Baselines v0.1

작성일 / Date: 2026-11-12

최신 실행 / Latest run: 2026-11-12 KST

## 결론

A1은 팀·차량·출발 좌표·근무시간·인원·장비·기술·필수·제외·고정 업무를 하나의 검증 가능한 JSON으로 표현한다. A2는 이 입력과 현재 위험 우선순위를 사용해 `risk_first`와 `nearest` 두 기준선을 결정적으로 생성한다.

실데이터에서는 현재 시점 예보 22행 중 점수와 순위가 유효한 14행을 골랐다. 같은 도로 링크에 여러 이벤트가 있으면 중복 출동하지 않도록 한 작업으로 합쳐 10개 현장 작업이 됐다. 운영자 제외 링크 1개를 뺀 9개 작업은 두 기준선 모두 배정했으며 제약 위반은 0건이었다.

## A1 자원 입력 모델

예시 시나리오는 팀 3개, 순찰차 3대, 팀당 2명, 계획 시작 후 2시간을 표현한다. 검증기는 다음 오류를 결과 생성 전에 차단한다.

- 중복 팀·차량 ID와 차량의 두 팀 중복 사용
- 차량 상태와 탑승 정원 초과
- 좌표 오류, 시간대 없는 시각, 역전된 교대시간, 계획 시작이 근무시간 밖인 경우
- 필수 링크와 제외 링크 충돌
- 없는 팀을 지정한 고정 업무와 한 링크의 중복 고정
- 작업시간 범위 오류와 장비·기술 요구 형식 오류

차량 장비와 팀 장비는 팀의 사용 가능 장비로 합쳐진다. 실제 인증키나 개인정보는 자원 JSON에 넣지 않는다.

## 현장 작업 정규화

배분 단위는 이벤트 행이 아니라 `effective_link_id`다. 같은 링크의 여러 이벤트는 다음 규칙으로 한 작업이 된다.

1. 점수 사용 가능하고 순위 대상인 선택 시간지평의 행만 사용한다.
2. 링크별 최고 위험점수를 대표 점수로 사용한다.
3. 모든 원본 `event_id`, 원천, 이벤트 종류와 건수를 보존한다.
4. 운영자 작업시간·필요 기술·필요 장비 덮어쓰기를 적용한다.
5. 필수·제외·고정 조건을 작업 속성으로 보존한다.

| 항목 | 실데이터 결과 |
| --- | ---: |
| 현재 시간지평 입력 | 22행 |
| 점수·순위 유효 이벤트 | 14행 |
| 고유 링크 현장 작업 | 10개 |
| 합쳐진 중복 이벤트 | 4건 |
| 좌표 결측 작업 | 0개 |
| 운영자 제외 | 1개 |
| 배분 후보 | 9개 |

## A2 기준선 규칙

`risk_first`는 고정 업무를 먼저 반영하고 필수 작업을 우선한 뒤 위험점수 내림차순으로 작업을 선택한다. 선택한 작업은 직선거리가 가장 짧은 실행 가능 팀에 준다.

`nearest`도 고정·필수 조건을 먼저 지키지만, 이후에는 전체 실행 가능 팀–작업 쌍 중 직선거리가 가장 짧은 쌍을 반복 선택한다. 두 방식 모두 장비·기술·팀당 작업 수·남은 근무시간을 지키며, 배정하지 못하면 원인을 출력한다.

| 지표 | 위험순 | 최근접 |
| --- | ---: | ---: |
| 배정 / 후보 | 9 / 9 | 9 / 9 |
| 위험가중 커버리지 | 100.0% | 100.0% |
| 직선거리 합계 | 78.736 km | 71.878 km |
| 추정 이동시간 합계 | 118.103분 | 107.818분 |
| 최대 팀 소요시간 | 92.051분 | 101.828분 |
| 팀별 작업 수 | 3·3·3 | 3·3·3 |
| 고위험 미배정 | 0개 | 0개 |
| 제약 위반 | 0건 | 0건 |

최근접은 직선거리 프록시를 6.858 km 줄였지만 한 팀의 최대 소요시간은 위험순보다 9.777분 길었다. 모든 작업을 배정할 수 있는 여유 있는 시나리오라 위험가중 커버리지는 같았다. 자원이 부족한 테스트에서는 위험순이 고위험 작업을 먼저 남기고, 최근접은 가까운 저위험 작업을 먼저 남길 수 있음을 자동화 테스트로 고정했다.

## 안전장치와 미배정 설명

- 동일 링크를 두 팀에 배정하지 않는다.
- 운영자 제외 링크를 배정하지 않는다.
- 고정 업무가 불가능해도 다른 팀으로 몰래 바꾸지 않고 `fixed_team_infeasible`로 남긴다.
- 기술·장비 부족, 작업 수 한도, 근무시간 부족, 좌표 결측을 서로 다른 사유로 기록한다.
- 필수 또는 고정 링크가 위험 작업 표에 없으면 제약 위반으로 표시한다.
- 각 배정에 전역 선택 순서, 팀 내 방문 순서, 선택 이유와 누적 시간을 남긴다.

## 중요한 한계

현재 이동거리는 위경도 대권거리이며 기준 속도 40 km/h로 시간을 환산한다. 실제 도로 경로, 통제, 회전 제한, 혼잡을 반영한 ETA가 아니다. 따라서 이 결과는 기준선이지 운영 최적안이 아니다. 다음 단계 T1에서 도로 이동시간 행렬로 교체하고, A3에서 위험 커버리지·이동시간·업무량을 함께 최적화한다.
