# RoadOps 0·1·3·6시간 운영 우선순위 시나리오 v0.1

작성일 / Date: 2026-11-12
최신 실행 / Latest run: 2026-11-12 22:11 KST

## 결론

F1 v0.1은 22개 C-ITS 현장 이벤트와 13개 기상격자의 현재·1·3·6시간 실황·예보를 결합해 88행의 운영 우선순위 시나리오를 만든다. 이 값은 사고발생확률이 아니다. 진행 중 이벤트가 해제시각 없이 지속된다는 시나리오와 해당 시각의 날씨 예보를 기준으로 한 현장 검토 순서다.

구조 품질검사는 0건 실패했고, 88개 `forecast_id`는 모두 고유했다. 미래 시점에 현재 ITS 교통값이나 C-ITS 노면센서값을 복사한 행은 0건이다. 항공·여객선 관문 유입압력도 0으로 대체하지 않고 88행 모두 `unavailable`로 표시했다.

현재 22행에서 14행이 점수를 받았고 8행은 `hold`다. 1·3·6시간은 각각 8건만 점수를 받았다. 이 8건은 도로위험 이벤트이며, 해제시각이 없어 지속 시나리오를 평가한다. 현재 노면센서 행은 미래 시점으로 복사하지 않아 근거 커버리지 60% 미만으로 `hold`됐다.

## 시점별 근거 규칙

| 근거 | 현재 | 1·3·6시간 |
| --- | --- | --- |
| C-ITS 도로 이벤트 | 최신 수집 스냅샷 | 해제시각 없음을 명시한 지속 시나리오 |
| 기상 | 초단기실황 | 초단기·단기예보 |
| C-ITS 노면센서 | 현재 관측값 | 복사하지 않음 |
| ITS 교통 | 현재 관측값 | 예측 모델이 없어 결측·불확실성으로 처리 |
| 구조위험 | TAAS·제주데이터허브 선행값 | 같은 도로 구조적 선행값 |
| 항공·여객선 | `unavailable` | `unavailable` |

미래 교통과 관문 유입은 빠진 근거가 모두 낮은 위험이라는 뜻이 아니다. 빠진 근거가 0점이라고 가정했을 때의 하한과 100점이라고 가정했을 때의 상한을 같이 제공한다.

## 안전장치

- `forecast_semantics=operational_priority_scenario_not_accident_probability`를 모든 행에 보존
- 해제시각이 없는 이벤트를 유지할 때 `persistence_scenario_without_end_time` 표시
- 미래 ITS 교통과 C-ITS 노면센서 현재값 복사 금지
- 결측값을 0점으로 대체하지 않고 상·하한에 반영
- 근거 커버리지 60% 미만이면 점수 자체를 `hold`
- 시간지평별 독립 순위와 현재 대비 점수 변화를 분리
- 관문 유입 API 실패를 0명·0편으로 표시하지 않음

## 한계와 다음 게이트

1. v0.1은 날씨 예보와 이벤트 지속 시나리오이며 학습된 사고확률 모델이 아니다.
2. 1·3·6시간 ITS 교통 예측은 아직 없다. 시간·일간 통계와 최근 추세를 시점고정 방식으로 검증해야 한다.
3. 기상특보·행사·공휴일 피처는 아직 없다.
4. 항공·여객선 API가 복구되기 전까지 `gateway_inflow_pressure`는 비활성화한다.
5. F2에서 지속성 기준선과 시점고정 재생을 비교해 미래정보 누수가 없는지 검증해야 한다.
